Windows

Windows on x86-64, PowerShell 5.1 or newer. Open PowerShell as Administrator. The helper checks the official MSI signature and installs without a password in the MSI arguments.

Linux

Debian/Ubuntu and RHEL/Fedora-compatible systems with systemd, on x86-64 or ARM64. Requires curl and sudo to start; missing Python/OpenSSL utilities are installed after confirmation.

Read/download the Bash script

The device needs to reach the manager on TCP 1515 for enrollment and TCP 1514 for events. Existing agent installations are refused. A failed enrollment leaves the new agent stopped; use the official tools to diagnose/retry it.

Security and manual installation

These commands download to a file, check the script and release hashes, then run locally. Windows unblocks only that verified script; managed execution policies still apply. The helpers use official packages and native certificate-verified enrollment, remove the temporary password file, and leave remote commands and Active Response disabled. Enrollment is performed once; future re-enrollment uses the manual workflow.

Running downloaded code as administrator requires trusting this website and its GitHub account. Hashes copied from this same page do not protect against a compromised website. Review the scripts before running them.

Prefer the official manual workflow? Download this public certificate, use Deploy new agent in the dashboard, and supply the password and registration CA setting before starting the service.

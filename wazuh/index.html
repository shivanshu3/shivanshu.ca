Security and manual installation

These commands download and run the current installer over HTTPS. The helpers check official package hashes (and the Windows MSI signature), verify the enrollment certificate, remove the temporary password file, and leave remote commands and Active Response disabled. Enrollment is performed once; future re-enrollment uses the manual workflow.

Running downloaded code as administrator requires trusting this website and its GitHub account. A compromised website could replace both the installer and its checks. Review the scripts before running them.

Prefer the official manual workflow? Download this public certificate, use Deploy new agent in the dashboard, and supply the password and registration CA setting before starting the service.

Remove an agent and start fresh

This permanently deletes the local Wazuh agent, configuration, logs, enrollment keys, and saved agent backups. No backup is made. The helper shows its targets and requires you to type REMOVE before making changes.

Windows uses the registered MSI, then removes leftover agent directories and agent-specific service/registry entries. Linux uses APT or DNF/Yum, then removes /var/ossec, agent service files, and its dedicated account. Linux refuses to run on a Wazuh manager. Use these commands on the device you want to reset.

Windows removal

Open PowerShell as Administrator.

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "irm https://shivanshu.ca/wazuh/uninstall.ps1 | iex"

Linux removal

Debian/Ubuntu and RHEL/Fedora families with systemd.

curl -fsSL https://shivanshu.ca/wazuh/uninstall.sh | sudo bash

Read/download the removal script

For a fresh enrollment, have the server owner remove the device's old manager registration before reusing its name, then run the installation command above. Reboot first if Windows requests it.

Removal covers the agent installation and its local data. Manager records, shared OS event/journal history, and copies you saved outside the agent directory are separate. These commands trust this HTTPS website and its GitHub account.
